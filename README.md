# Maya Tools
Scripts for Maya

---

How To:
1. Copy the script you want to run.
2. Paste it on the script editor window in Maya.
3. RUN IT

---
How to save Script in Maya Shelf:
1. Paste code on script editor window in Maya.
2. Select all, then drag & drop into shelf.
3. After that, the script should run by just clicking the Icon.
